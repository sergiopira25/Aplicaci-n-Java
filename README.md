# Aplicación de Validación de Contraseña

Esta aplicación en Java permite al usuario ingresar una contraseña y valida si cumple con los siguientes requisitos:
- Al menos 8 caracteres.
- Al menos un número.

Si la contraseña no es válida, el sistema permite intentar nuevamente.

## Estructura del proyecto
- **model**: Contiene la clase `Password`.
- **service**: Contiene la clase `PasswordValidator`.
- **ui**: Contiene la interfaz `PasswordUI`.
- **main**: Contiene la clase `Main` que inicia la aplicación.
